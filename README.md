# filoviruses
Code for serological study of filoviruses in bats and huamns in Ghana.

There are three subsets of data analysed in the accompanying study. Data are provided for all three cases in respective folders. The data contain both raw EBOV and MARV MFI values as well as the logged and rescaled ("rs") values. The study methods describe how these corrections were applied, and the necessary MFI values for all positive controls, monoclonal antibodies, and blank wells are provided for bats (2012-2019) and humans. For 2019-2020 bats, corrections were made with mock bead values and the raw data and code for this are provided.

Analysis code for each of the three datasets is also provided in each folder so that analyses can be reproduced with the corrected data.
